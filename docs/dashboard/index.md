# ダッシュボードの基本操作

## ナビゲーション

左のサイドレールには「概要」「サーバー情報」と、カテゴリーごとの機能が並びます。「サーバー運営」からサポートチケットとリアクションロールを開けます。ほかの機能は「コミュニティ」「エンゲージメント」「モデレーション」「通知・ソーシャル」から選びます。モバイルでは上部のメニューボタンから同じ機能を開けます。

検索ボタン、`Ctrl+K`または`Command+K`で機能検索を開きます。機能名とカテゴリー名で検索できます。サーバーを切り替える場合は、上部のサーバー名からサーバー一覧へ戻ります。

サポートチケットでは概要、受付一覧、受付設定、履歴、統計、設定を切り替えます。受付設定にはパネル・配置メッセージ・フォーム・担当チーム・タグをまとめています。チケット担当Staffには概要・受付一覧・履歴が表示されます。リアクションロールではメッセージ一覧、Link Group、操作履歴、設定、作成を切り替えます。

「サーバー情報」でDiscordから取得したサーバー名・ID、チャンネル数・ロール数、必要権限の不足を確認します。各機能の設定はその機能の画面で編集します。

## リソースの選択

Channel、Category、Role、EmojiはDiscordサーバーから取得した候補から選択します。数値IDの手入力は通常不要です。

複数選択では「すべて選択」「選択を反転」を利用できます。WhitelistとBlacklistは同時に設定せず、対象画面のアクセス方式を先に選択します。

## 表示設定

言語、外観、カラースキーム、サイドレール状態はDiscordユーザー単位で保存されます。外観はPrecision、Community、Atmosphere、カラースキームはsystem、light、darkから選択できます。

## ログアウト

アカウント表示の右側にあるログアウトを選び、確認Dialogから実行します。Discord自体のログイン状態は維持されます。

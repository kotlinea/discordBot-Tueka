# モデレーションルールの作成と再利用

モデレーションカテゴリーからAutoMod・Anti-Spam・Anti-Raidを開きます。同じ検知方法のルールを複数作成し、対象チャンネル・しきい値・処置を分けられます。

## 作成・複製

1. 「ルールを作成」を開きます。「既定値から作成」で検知方法を選び、「既定値を読み込む」を押すと初期設定が入ります。
2. 名前、検知設定、適用範囲・例外、処置を指定し、確認して保存します。作成直後のルールは無効です。
3. 似たルールを作る場合は一覧の「ドラフトを複製」を使い、名前や対象を変更して保存します。保存前には新しいルールは作られず、複製元も変更されません。

編集中に既定値を読み込むと、入力内容を置き換えるかどうか確認されます。取得や保存が失敗しても入力は残ります。参照先が削除・閲覧不能になった場合は、表示されるIDを確認して利用可能なチャンネル・ロールを選び直してください。

## 保存済みルールをまとめて切り替える

1. 一覧で対象を選択します。「表示中のルールを選択」は検索結果を対象にします。
2. 「選択を有効化」または「選択を無効化」を押します。
3. 件数、監視・実行モード、必要な権限、実行条件を確認して「状態変更を確定」を押します。

停止や再有効化の際も、ルールの内容、順序、履歴はそのまま残ります。作り直す必要はありません。これは保存状態の変更であり、Banなどの処置をその場で実行する操作ではありません。親のモデレーション設定や各機能が停止中なら、ルールを有効にしても保護は開始しません。Bot権限、参照先、実行時のロール階層なども必要です。

順序変更・削除の未保存編集がある場合は、先に保存または破棄してください。一括変更中は重複送信や画面移動ができません。

別の管理者による変更と競合した場合は全件変更されません。「再取得して選択を確認」で最新値を読み込み、対象を再確認して確定します。削除済みの対象は再取得時に選択から外れます。権限不足や入力エラーでも、選択したルールはそのまま残ります。

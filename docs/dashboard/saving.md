# 保存と競合

## 明示保存

変更すると固定Save Barへ変更件数、保存、破棄が表示されます。保存前の変更はBotへ反映されません。画面を離れる場合だけ未保存警告が表示されます。

削除や並べ替えも保存前はDraftです。破棄すると最後に取得したサーバー上の値へ戻ります。

## 409 Conflict

設定とルールにはrevisionがあります。別の管理者が先に更新した場合、古いrevisionでの保存は409になります。

1. 現在の入力を必要に応じて控えます。
2. 画面を再読込して最新設定を取得します。
3. 差分を確認して再度保存します。

409を無視して上書きする操作はありません。

## 422 Validation Error

入力値、Discordリソース所属、Role階層、Action競合などが無効です。エラーの`path`に対応する入力を修正します。他サーバーのChannel IDやRole IDは保存できません。

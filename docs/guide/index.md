# Tuekaについて

TuekaはDiscordサーバーのモデレーション、チケット対応、ロール付与、投票、提案、SNS通知を提供します。

- 一般メンバーは、コマンド、公開パネル、投票、提案を利用します。
- サーバー管理者・モデレーターは、付与された権限の範囲で設定や処置を行います。
- システム運用者は、Botのホスト、配布、障害対応を担当します。接続やサービスの障害については運用者へ問い合わせます。

[利用を始める](./getting-started) → [ダッシュボード](../dashboard/) → [全コマンド](../reference/commands)の順に確認してください。

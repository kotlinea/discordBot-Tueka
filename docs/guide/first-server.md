# 最初のサーバー設定

1. **サーバーログ**の送信先を設定します。
2. **Moderation**でBot、Webhook、管理Role、管理Channelの例外を確認します。
3. AutoModルールをmonitorで作成し、プレビューと実ログで誤検知を確認します。
4. 問題がなければenforceへ変更します。
5. Community機能を一つずつ有効にし、Discord側で動作確認します。
6. Social通知を使う場合はWorkerが「稼働中」になってから購読を登録します。

設定のトグルを切り替えただけではBotの動作は変わりません。画面下部の保存操作を完了し、保存状態が更新されたことを確認してください。

# 利用を始める

## 一般メンバー

1. Botが参加済みのサーバーで `/help` を開きます。
2. [全コマンド](../reference/commands)から目的の機能と必要権限を確認します。
3. チケット・リアクションロールなどはサーバー管理者が公開したパネルから利用します。

## サーバー管理者

1. システム運用者から共有されたBot招待リンクを開き、管理するサーバーへ招待します。
2. Botの権限とロール階層を[権限ガイド](./permissions)で確認します。
3. ダッシュボードへDiscordでログインし、管理するサーバーを選びます。
4. 必要な機能だけを有効にし、チャンネル・ロール等を設定して保存します。
5. 保存結果を再読込で確認し、Discordで `/ping` と `/help` を試します。

サーバーが表示されない場合はManage Server権限とBotの参加状態を確認してください。Botの招待リンクや公開URLが不明な場合はシステム運用者へ問い合わせます。利用者がトークンやサーバーの接続設定を入力する必要はありません。

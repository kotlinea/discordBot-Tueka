# X通知

登録したアカウントの更新を通知します。取得方法と利用可否はシステム運用者が管理します。

## 登録

アカウントIDまたはハンドルと通知チャンネルを指定します。

## 利用と確認

保存後の対象解決を待ち、プレビューで通知を確認します。取得方式は利用者ごとには切り替えません。

通知先のBot権限とロール階層を確認し、通知ロールは専用選択欄で指定します。通知サービスの利用可否は運用者の設定によります。

## 問題が起きたら

通知サービス側の制限によって遅延することがあります。対象が公開されているか確認し、継続する失敗は運用者へ伝えます。

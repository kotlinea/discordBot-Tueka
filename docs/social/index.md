# 通知・ソーシャル

サーバー管理者はダッシュボードで対象アカウントと通知チャンネルを登録します。通知ロールは専用の選択欄で指定してください。本文へ直接メンションを追加しないでください。

1. 通知サービスを選び、アカウントIDまたはハンドルと通知チャンネルを設定します。
2. 保存直後の「確認待ち」から「稼働中」への変化を確認します。初回確認を基準に、それ以降の新着を通知します。
3. プレビューでイベント別テンプレートを確認します。

既定では1サーバー・1通知サービスにつき10対象までです。利用可能な通知サービスと上限はシステム運用者の設定によります。

テンプレートでは `{account}`、`{handle}`、`{title}`、`{text}`、`{url}`、`{platform}`、`{event}`、`{published_at}`、`{thumbnail}`、`{avatar}`、`{viewer_count}` を使用できます。

チャンネル消失や権限不足は設定を修正してください。確認待ちや失敗が続く場合は通知サービス名、対象、時刻、画面の状態を運用者へ伝えてください。

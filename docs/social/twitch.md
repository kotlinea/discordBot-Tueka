# Twitch通知

配信開始・終了など、画面で選択したイベントを通知します。

## 登録

Twitchのアカウントを指定し、解決された対象を確認します。

確認済みのアカウントは、ユーザー名を変更しても同じユーザーを監視します。定期確認の間に別の配信へ切り替わった場合は、前の配信の終了と新しい配信の開始を通知します。

配信開始・終了の受信後にTwitchへ現在の配信状態を確認してから通知します。登録後の初回確認では、その時点の状態を記録します。以後の確認で開始・終了を検出すると通知するため、初回確認前に始まって終了した配信は通知されません。Twitchへの確認が失敗した場合は、再試行後に確認できた状態を通知します。

## 利用と確認

通知チャンネルとイベント別テンプレートを保存し、プレビューで表示とメンションを確認してください。

通知先のBot権限とロール階層を確認し、通知ロールは専用選択欄で指定します。通知サービスの利用可否は運用者の設定によります。

## 問題が起きたら

確認待ちが続く場合はアカウント名とチャンネル権限を確認し、運用者へ問い合わせます。

# Getting started

## Members

Use `/help` in a server where Tueka is installed. Check the [command reference](./reference/commands) for permissions. Use the ticket and reaction-role panels published by server managers.

## Server managers

1. Obtain the Bot invitation link from the system operator and invite it to your server.
2. Check [Bot permissions and role hierarchy](./guide/permissions).
3. Sign into Dashboard with Discord and select your server.
4. Enable only the required features, choose channels/roles, then save.
5. Reload to verify settings and try `/ping` and `/help` in Discord.

If a server is missing, check Manage Server permission and Bot membership. Ask the operator for the invitation or Dashboard URL. Users do not need hosting credentials or Bot tokens.

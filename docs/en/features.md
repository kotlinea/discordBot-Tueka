# Features

## Suggestions

Members run `/suggest` to open a private submission modal. Tueka posts the answers as an embed in the configured channel, where members can vote and authorized reviewers can mark the suggestion as in review, approved, or rejected.

## Moderation

Rules share an Event → Trigger → Conditions / Exemptions → Actions → Case / Log pipeline. AutoMod handles content, Anti-Spam handles rate windows, and Anti-Raid handles join and leave activity.

## Community

Welcome messages, automatic roles, leveling, temporary voice channels, live statistics, native reaction roles, and the complete Ticket workflow are managed per guild.

## Social

The Social Worker monitors YouTube, Twitch, X, TikTok, and Instagram. Official webhook or API paths are preferred; unofficial public-page adapters are explicitly best effort.

## Tickets and Reaction Roles

Tickets support channel and private-thread modes, forms, teams, claiming, feedback, encrypted transcripts, and an outbox. Reaction Roles support normal, unique, verify, binding, drop, reversed, temporary, and locked behavior.

# Saving and conflicts

Changes remain a draft until you use Save in the fixed bar. The bar shows changes, Save and Discard. Leaving an edited page warns about unsaved changes. Deletion and reordering are also drafts; Discard restores the last loaded values.

## Conflict (409)

Another manager saved a newer revision. Preserve your intended edits, reload, compare and reapply them. There is no force-overwrite operation.

## Validation (422)

Correct the highlighted field: invalid values, conflicting actions, wrong-server resources or role hierarchy. Resources from another server cannot be saved.

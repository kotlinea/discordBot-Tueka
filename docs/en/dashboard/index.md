# Dashboard basics

The side rail contains Overview, Server information, and features grouped by category. Open Support tickets and Reaction Roles under Server operations. Find other features under Community, Engagement, Moderation, and Social & notifications. On mobile, open the top menu. Use the search button, Ctrl+K or Command+K to search by feature or category name. Select the server name to return to the server list.

Support tickets has Overview, Inbox, Intake setup, Transcripts, Stats, and Settings. Intake setup groups panels, panel messages, forms, staff teams, and tags. Ticket staff can access Overview, Inbox, and Transcripts. Reaction Roles has Messages, Link groups, Audit events, Settings, and Create Reaction Role.

Server information displays the server name and ID, channel and role counts from Discord, and missing required permissions. Edit each feature's settings in its own screen.

Choose channels, categories, roles and emoji from Discord resource pickers. Multi-select supports select-all and invert-selection. Select one access policy before entering whitelist/blacklist targets.

Language, appearance and rail preferences belong to your Discord account. Choose Precision, Community or Atmosphere and system, light or dark color schemes. Logout uses a confirmation dialog and does not log you out of Discord itself.

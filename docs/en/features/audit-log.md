# Server logs

Select a management channel and enable the message, voice, channel, member, role or server-setting categories you need. The Bot needs View Channel, Send Messages and Embed Links. View Audit Log is required to identify administrative actors.

Deleted message content can only be included if the Bot saw it before deletion. Missing events cannot be reconstructed. Detection and sanctions appear in [Moderation Logs](./moderation-logs); the Bot suppresses duplicate records for its own actions.

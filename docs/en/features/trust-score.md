# Trust Score

Trust Score is an administrator reference based on moderation cases and infraction history, not a public member rating or an independent punishment mechanism.

Configure history retention from 1–3650 days and a flag threshold from 0–100. Cancellations and expiry affect recalculation. Configure automatic sanctions through [Infractions](./infractions) point thresholds instead.

# Moderation

Moderation connects detection, sanctions, cases and logs: event → trigger → conditions/exemptions → monitor/enforce → actions → case/log.

Evaluate the event and actor, global exemptions, feature-specific exemptions, trigger and conditions before actions. Use monitor mode to inspect matches before enforcing. Validate both matching and excluded users/channels in preview.

Server managers configure rules. Acting moderators and the Bot need the relevant Discord permissions and role hierarchy. Inspect each action result after partial failure. Correct false positives by changing the rule and cancelling the relevant case; cancellation does not automatically undo every action already performed in Discord.

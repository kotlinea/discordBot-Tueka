# Warnings / Infractions

Manage manual and automatic warnings, points, cases, cancellation, expiry and escalating sanctions. A warning adds its configured points and may expire.

Threshold actions fire only when active points cross upwards: only the highest of simultaneous thresholds fires; another crossing after expiry can fire again; remaining above a threshold does not repeat that action. Cancelled cases do not contribute active points.

Search a user to inspect points, warning count, reason, source, moderator, expiry, cancellation and related moderation events. Manual adjustments and cancellations are audited. The point total includes records that are active and have not been cancelled.

# Welcome and leave messages

Joining and leaving notifications are enabled separately. For each, choose a text channel, text/embed format and body; an empty body uses the default template.

Text supports up to 2,000 characters and embed descriptions up to 4,096. Use the variables shown by the editor, such as member mention, username, server name and member count. Unsupported braces remain literal.

After saving, test channel permissions and mentions with a test member. The Bot needs View Channel, Send Messages and Embed Links for embeds.

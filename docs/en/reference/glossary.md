# Glossary

| Term | Meaning |
| --- | --- |
| Actor | User, Bot or webhook that caused an event |
| Trigger | Rule detection mechanism |
| Condition | Required AND condition |
| Exemption | Excluded user, role or channel |
| Action | Removal, warning, timeout or notice |
| Case | A moderation history record |
| Revision | Version used to detect conflicting edits |
| Lease | Time-limited ownership of a job |
| Outbox | Queue retaining external delivery work |
| Cursor | Last observed provider event position |
| Best effort | Depends on unofficial external behavior; continuity is not guaranteed |

# Permissions

Members need access to the relevant server and channel. Server managers configure Bot roles; connectivity and privileged event settings are the operator’s responsibility.

| Bot permission | Use |
| --- | --- |
| View Channel / Send Messages | Responses, notices, panels |
| Embed Links / Attach Files | Embeds and transcripts |
| Read Message History | Tickets and reaction-role messages |
| Manage Messages | Removal, purge, reactions |
| Manage Roles | Automatic and reaction roles |
| Moderate Members | Timeouts |
| Kick Members / Ban Members | Corresponding sanctions |
| Manage Channels | Locks, temporary channels, tickets |
| Manage Threads / Create Private Threads / Send Messages in Threads | Private-thread tickets |
| Move Members | Temporary voice channels |
| View Audit Log | Identifying action actors |

The Bot must be above the target role/member. Server permission alone does not override channel/category overwrites. Check both when only one channel fails.

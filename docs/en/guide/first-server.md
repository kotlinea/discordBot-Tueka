# First server settings

1. Choose a server log destination.
2. Review Bot, webhook, administrator-role and channel exemptions in Moderation.
3. Create AutoMod rules in monitor mode and check preview/logs for false positives.
4. Switch to enforce only after checking results.
5. Enable Community features one at a time and verify them in Discord.
6. Check social notification availability before adding subscriptions.

A toggle alone does not save. Use the Save bar and verify the saved state.

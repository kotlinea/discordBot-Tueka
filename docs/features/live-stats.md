# ライブ統計チャンネル

メンバー数などの値をボイスチャンネル名へ反映します。表示専用チャンネルを選択し、チャンネル名テンプレートを設定します。

参加・退出・ロールの作成や削除による表示更新は5秒ごとにまとめて行い、5分ごとに値を再確認します。

BotにManage Channelsが必要です。Discordにはチャンネル名の更新回数に制限があるため、イベントごとに即座に反映されない場合があります。テンプレートを空にした場合は初期値を使用します。

機能を無効化しても、チャンネルと最後に設定された名前はそのまま残ります。

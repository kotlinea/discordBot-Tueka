# Starboard / Highlights

選択したチャンネルの投稿を、リアクション数に応じて紹介します。管理者はDashboardの「Starboard / Highlights」で機能をONにし、Boardを作成します。最大10件のBoardに、投稿元・紹介先・絵文字・閾値を設定できます。

## 投稿元と集計

投稿元は1〜25チャンネルを明示選択します。親チャンネルを選ぶと、その公開Threadも対象です。非公開Threadを紹介するには、そのThread IDを投稿元へ個別に追加してください。親チャンネルの指定だけでは、非公開Threadの本文や投票者を取得しません。チャンネル・Threadを最大25件除外できます。NSFWの投稿、Bot投稿、投稿者本人とBotによる票は集計対象外です。通常リアクションとスーパーリアクションを合わせ、同じ人を1人として数えます。

非公開Threadを個別指定すると、その本文を紹介先へ投稿します。紹介先を閲覧できる人に内容を公開してよいことを確認してください。

すでに紹介されている非公開Threadも、次に元投稿の取得や紹介の更新を行う際に個別指定を確認し、対象外なら取り下げます。その処理が行われるまでは、既存の紹介が残る場合があります。

閾値は1〜100人、集計上限は5000人です。上限を超えた場合は部分集計で公開せず、取得失敗として扱います。取得に必要な閲覧・履歴権限と、紹介先への投稿・埋め込み権限をBotに付与してください。

## 投稿の更新と配送

閾値に達すると、本文の先頭2000文字・投稿者表示名・画像1件・元投稿リンクを紹介先へ投稿します。元投稿の編集、票数の変化、閾値割れ、元投稿の削除に追従します。投稿先を変えた場合は、Tueka自身の記録済み投稿を取り下げ、新しい紹介先へ配送します。

元投稿・Thread・親チャンネルの削除、または親チャンネルのNSFW化では、保持中の本文・画像を消して紹介投稿を取り下げます。NSFWの元投稿本文や投票者は取得しません。

配送の応答が不明な場合、直近200件から受領を照合します。見つからない場合は自動で再送せず、失敗状態とします。管理者は履歴を確認して再試行できます。再試行でも同じ記録を使い、無条件の二重送信を避けます。

## 無効化と保存期限

機能全体のOFFは、取得と配送を停止します。記録は保存期限内で閲覧できます。Board単体のOFFは、そのBoardで紹介したTuekaの投稿を取り下げます。機能全体がOFFの間は、この取り下げも再開まで待機します。

新規記録の保存期限は1〜365日、既定30日です。作成済み記録の期限は設定変更で延長しません。期限切れの本文・履歴・配送記録は削除します。Discord上の元投稿と紹介投稿は、この保存期限では自動削除しません。期限後は編集・削除追従が終了するため、必要な紹介投稿の整理はDiscordで行ってください。

同じ投稿の再紹介を防ぐため、Boardが存在する間はBoard IDと元投稿IDだけを残します。本文・票数・投稿者情報は保存期限で削除します。すでに保存記録を削除した投稿のIDは復元できず、再紹介を防げない場合があります。

1Boardにつき保存期限内の紹介記録は最大1000件です。取得待ちはGuildごとに最大1000件、イベントの再取得期限は1日です。同じ投稿への短時間のイベントはまとめて処理します。バックアップには設定・期限内記録・受領情報を含みます。

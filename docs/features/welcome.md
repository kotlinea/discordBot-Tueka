# 入退室メッセージ

メンバーの参加・退出時に、指定チャンネルへテキストまたは埋め込みを送信します。参加と退出は個別に有効化できます。

## 設定

| 設定 | 必須条件 | 説明 |
| --- | --- | --- |
| ウェルカムメッセージ有効 | 任意 | 参加通知を有効化 |
| ウェルカム送信先 | ウェルカムメッセージ有効時 | テキストチャンネルから選択 |
| 表示形式 | text / embed | Discordの通常本文または埋め込み |
| ウェルカム本文 | ウェルカムメッセージ有効時 | 空欄なら初期テンプレート |
| 退出メッセージの有効状態・送信先・形式・本文 | 退出メッセージ有効時 | 退出通知も同じ構成 |

テキストはDiscordの上限の2000文字以内、埋め込みの説明は4096文字以内です。

## テンプレート変数

設定画面に表示される変数を使用します。代表例はメンバーへのメンション、ユーザー名、サーバー名、メンバー数です。未対応の波括弧は置換されず、そのまま表示されます。

保存後はテスト参加用アカウントまたは検証環境でメンションとチャンネル権限を確認してください。

# Giveaways / Community Events

管理者はDashboardで機能をONにし、抽選または先着定員のイベント受付を作成します。タイトル、説明、投稿先、締切、定員と参加条件を設定して下書きを保存し、「Discordで公開」を選びます。公開するとBotの受付投稿に参加・取消ボタンが表示されます。公開後の条件変更はできません。必要なら中止して新しい受付を作成してください。

## 参加と締切

メンバーは受付投稿の「Join / 参加」で参加し、「Leave / 参加を取り消す」で撤回できます。本人だけが応答を受け取ります。Botは参加できません。許可ロールはいずれか1つを必要とし、拒否ロールが優先します。アカウント作成・サーバー参加からの日数も指定できます。参加時と締切時に、サーバー所属と条件を確認します。

締切後の参加・取消はできません。イベント受付は定員の先着順で参加を受け付け、締切時に条件を満たす参加者を確定します。抽選では、条件を満たす候補から重複なしで当選者を選びます。候補が希望人数より少ない場合は候補数までを選びます。誰も残らなければ当選者なしで確定します。メンバー確認が途中で失敗した場合は、一部の候補だけで抽選せず処理を再試行します。

管理者は理由を付けて早期締切・中止を行えます。再抽選も理由が必要で、それまでの全回の当選者を除外します。過去の結果と理由・操作者・日時は履歴に残ります。イベント受付では再抽選を行いません。受付投稿に参加件数と当選者を表示しますが、メンション通知は送信しません。参加者全件と候補一覧はサーバー管理者だけがDashboardで閲覧できます。

## 失敗と無効化

投稿の閲覧・履歴取得・送信・埋め込み権限をBotに付与してください。告知の結果が未確定の場合は、同じBot投稿の目印を使って直近200件から受領を照合します。見つからない場合は重複を避けるため再投稿を停止します。権限や通信を確認し、履歴の失敗した処理を再試行してください。既存の受付投稿が削除された場合も自動で新しい投稿を作りません。

機能全体をOFFにすると受付・締切・告知を停止します。保存期限内の記録は閲覧でき、再開後に処理を継続できます。期限切れの削除はOFF中も行います。中止は履歴を残し、既存のDiscord投稿を削除しません。

## 上限と保存

1サーバー100件、定員1〜1000人、参加履歴1000人、ボタン操作履歴10000件、条件ロール各25件、当選者1〜20人、初回を含めて最大20回までです。締切は30秒後〜90日後、保存日数は1〜365日です。締切からの保存期限を公開時に固定し、再抽選でも延長しません。中止した場合は中止日時から保存日数を数えます。期限切れで内部の設定・参加情報・結果・履歴・処理記録を削除します。Discordの受付投稿とそこに表示した結果は自動削除しません。

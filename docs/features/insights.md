# Server Insights

管理者が、観測できた投稿数・参加数・退出数・音声チャンネルの接続時間をUTC日別に確認します。期間を選ぶとグラフと表に同じ集計が表示されます。

## 収集を始める

1. Server Insightsの「収集設定」を開き、投稿数と接続時間を記録するチャンネルを選びます。最大25件です。
2. 入退室も記録する場合は「参加・退出を数える」をONにします。
3. 保存日数を1〜365日の範囲で指定し、収集をONにして保存します。チャンネルが空の場合、投稿・接続時間は記録しません。

Botが接続している間の新しいイベントから集計します。Bot・Webhook、NSFW、非公開スレッド、AFKチャンネルは対象外です。選択したテキスト・Forumチャンネルの公開スレッドは親チャンネルの選択に従います。本文・添付・表示名・音声の内容は保存しません。

## 集計の読み方

照会は保持範囲内の最大90日です。「未観測」は0件と区別します。観測秒数はBotが連続して観測した時間で、通信障害や停止がある日は一日の全件を表しません。音声は発話量ではなく接続時間の合計で、複数人分を加算します。

再起動、切断、機能OFF、収集設定の変更をまたぐ時間は補完しません。観測間隔が90秒を超えた時間も集計しません。参加時刻を取得できない入退室、90秒より古く届いた投稿・参加通知、収集開始前や中断中に作られた遅延投稿は対象外です。過去の投稿をさかのぼって取得しません。

収集OFF後も保持範囲内の集計を閲覧できます。日別集計はUTC日の開始から保存日数で期限を迎え、後の更新で期限を延長しません。保存日数を短くすると古い集計が順次削除されます。重複排除用の短期IDは最大1日、接続状態の利用者IDは観測中だけ保持し、停止後は期限処理で削除します。削除はOFF中も行います。保存期間を延長しても削除済みの集計は戻りません。

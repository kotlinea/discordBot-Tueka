# ミニゲーム

`/rps` でBotとじゃんけんができます。handでグー・パー・チョキを選ぶと、実行したチャンネルに双方の手と勝敗が表示されます。

```text
/rps hand:グー
```

サーバー管理者がミニゲームを有効にしたサーバーで利用できます。Botには対象チャンネルのView ChannelとSend Messagesが必要です。機能が無効な場合は、実行者に案内が表示されます。

引数と応答の公開範囲は[コマンド一覧](../reference/commands.md)を参照してください。

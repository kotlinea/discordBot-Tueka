# ミニゲーム

Discord内で短時間に遊べるコミュニティ向けゲームを提供します。利用できるゲームは`/help`のミニゲーム分類で確認できます。

Botには対象ChannelのView Channel、Send Messages、Embed Linksが必要です。ゲーム進行中のButtonは開始したSessionにだけ作用し、期限切れ後は操作できません。

管理者は機能を無効化できます。無効化後に新しいSessionは開始できませんが、すでに送信済みのMessageは自動削除しません。

# 拡張投票

投票を作成し、参加ロール、複数選択、結果の公開範囲、締切を設定できます。Dashboardの「拡張投票」では一覧、作成、編集、複製、移動、終了・再開、結果の取得、操作・配送履歴を確認できます。

## 作成する

サーバー所有者、Administrator、Manage Server、または投票管理を委譲されたロールが操作します。

```text
/poll question:次のイベントはいつ開催する？ options:土曜日|日曜日|祝日
/poll-time question:昼食は？ options:和食|洋食 time:3h
/pollbuilder question:次のイベントについて
```

`/poll` と `/poll-time` は2〜20択、BuilderとDashboardは2〜25択です。質問は1024文字、説明は2000文字、各選択肢は256文字まで。最大選択数は1〜20で、選択肢数以下に設定します。21択以上は選択メニューになります。長い選択肢は「選択肢・結果を確認」からページを切り替えて全文を読めます。

`/poll` のduration_minutesは1〜43200分、image_urlはHTTP/HTTPSの画像URLです。期間を省略すると手動終了します。Builderはプレビューを確認してCreateで公開します。Dashboardは下書きを保存し、一覧の「公開する」で投稿します。画像は1枚、色と絵文字も指定できます。Dashboardのカスタム絵文字にはサーバーの絵文字を使用してください。

BotにはView Channel、Send Messages、Embed Links、Read Message Historyが必要です。スレッド、ピン留めなどの追加操作には対応する権限も必要です。

## 投票と匿名性

ボタンで単一選択できます。複数選択や選択メニュー型は本人限定の画面で選び、「投票を確定」を押します。空の選択を確定すると取り消せます。許可ロールが空なら全員、指定時はいずれか一つのロールが必要です。拒否ロール・ユーザーの指定を優先します。Botは投票できません。

| 方式 | 投票中 | 終了後 |
| --- | --- | --- |
| Anonymous（既定） | 結果公開、個票非公開 | 同じ |
| Public | 結果・参加者・個票公開 | 同じ |
| Secret Winner | 参加者のみ公開 | 結果・参加者・個票公開 |
| Reveal at End | 選択肢のみ | 結果・参加者・個票公開 |
| Blind | 選択肢のみ | 結果のみ公開 |
| Custom | 項目ごとに指定 | 項目ごとに指定 |

Customは票数・グラフ、順位、総投票数、参加者、個票を投票中・終了後それぞれに指定します。公開先は全員、管理権限を持つ人、非公開です。個票の公開先は参加者一覧の公開先以下にします。

AnonymousとBlindは管理者にも参加者・個票を公開しません。重複防止、取消、指定時の退出者の票削除のため、内部DBには利用者IDを保存します。DBとバックアップを扱う運用者からの匿名化を保証する機能ではありません。出力と管理画面も同じ公開範囲に従います。

## 予約・終了・重み

`/poll-schedule` のstartには `2027-01-01T12:00:00+09:00` のようなUTCオフセット付き日時を指定します。最大365日先まで予約できます。timeは `10m`、`3h`、`1d 3h 15m` の形式で、最長30日です。公開後の相対期間は実際に公開した時刻から数えます。処理は30秒周期のため公開・表示更新に遅れが生じる場合があります。

参加人数の上限、最多得票の告知、ピン留め、専用スレッド、退出・キック・BAN時の票削除はDashboardで設定できます。自動処理は初期状態で無効です。結果が非公開の投票は最多得票を告知しません。同率の場合は同率の選択肢を告知します。

ロールの重みは1〜100。複数該当時は最大値を、その回答を確定した時点で保存します。設定変更だけでは既存票を変更しません。再確定時には現在のロールと重みを評価します。参加人数、選択件数、重み付き得票は別に表示します。

## 管理する

`/poll-list`、`/poll-show poll_id:1` で確認し、`/poll-edit`、`/poll-close`、`/poll-reopen`、`/poll-move`、`/poll-copy`、`/poll-delete` で管理します。引数は[コマンド一覧](../reference/commands.md)を参照してください。

`/poll-show`、投稿の結果ボタン、結果画面のページ切替には、投票の投稿先チャンネルを閲覧する権限が必要です。非公開スレッドの結果は、そのスレッドの参加者またはManage Threads権限を持つ人が確認できます。

投票が一度でも入った後は、質問、説明、選択肢、参加条件、選択上限などを変更できません。色、画像、締切、上限人数は変更できます。個人情報の公開範囲を広げる編集もできません。再開しても票は残り、既に公開した情報を秘密に戻すことはできません。削除には明示的な確認が必要で、個票も消去します。

結果は `/poll-export poll_id:1 format:csv` またはDashboardからCSV/JSONで取得できます。Discordでは本人限定返信に添付します。最大8MiBで、公開範囲を超える個票は含みません。CSVでは数式として実行される値を無効化します。

権限・重み設定では投票閲覧、管理、個票閲覧、票削除、設定変更、重み変更をロールへ委譲できます。権限の割当はサーバー所有者などの管理者が行います。重み変更の権限だけでは管理権限を割り当てられません。

参加条件・重み・権限設定には、サーバー内の全ロールを指定できます。管理者ロール、Botより上位のロール、連携サービスが管理するロール、全員（@everyone）も対象です。

終了・取消・削除後の保存期間は既定90日、1〜365日で設定できます。未公開下書きは7日で削除します。送信結果を確認できない配送は確認が済むまで残ります。履歴の「要確認」は状態を確認して「配送を再確認」を実行してください。確認できない投稿を自動で重複送信しません。

拡張投票を無効にすると新規作成、投票、公開、任意の自動告知が停止します。閲覧、出力、手動終了・削除、期限確定と受付停止表示は続きます。停止中に締切を過ぎた予約は公開せず終了し、手動終了型の予約は再有効化後に公開します。削除されたDiscord投稿は自動再作成しません。

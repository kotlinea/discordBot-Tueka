# 一時的な音声チャンネル

メンバーが作成トリガーのボイスチャンネルへ参加すると、Botが専用のボイスチャンネルを作成してそのメンバーを移動します。誰もいなくなるとチャンネルを削除します。

Bot停止中に空室になったチャンネルは、機能が有効なときに起動後および約1分ごとの確認で削除します。作成直後の60秒間は、この定期削除の対象外です。

| 設定 | 必須 | 説明 |
| --- | --- | --- |
| トリガーチャンネル | はい | Discordのボイスチャンネルから選択 |
| 作成先カテゴリ | 任意 | 未設定時はトリガーと同じカテゴリ |
| チャンネル名テンプレート | はい | 空欄なら初期テンプレート |

チャンネル名テンプレートでは設定画面に表示されるユーザー名などの変数を使用できます。チャンネル名はDiscordの文字数上限に収まるように調整されます。

BotにはManage ChannelsとMove Membersが必要です。作成されない場合はトリガーがボイスチャンネルであること、カテゴリの権限設定、Botのロールを確認してください。

# 初期ロール

サーバーへ参加したメンバーへ、指定したロールを自動付与します。

ロールはDiscordサーバーから選択します。BotにManage Rolesがあり、Botの最上位ロールが付与対象ロールより上にある必要があります。外部サービスが管理するロールや`@everyone`は付与できません。

## 確認手順

1. 対象ロールを選択して保存します。
2. Discordのロール一覧でBotのロールを対象より上へ移動します。
3. テストメンバーを参加させます。
4. ロールが付かない場合はBotログ、ロール階層、Server Members Intentを確認します。

機能を無効化しても、すでに付与したロールは自動で削除されません。
